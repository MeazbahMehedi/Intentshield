INTEGRATIONS

Integrations

Local screening works immediately. The optional gateway supports Ollama through its non-streaming generation API.

Local engine

Regex and structured rules, bounded decoding, separate harmful-content and data checks, persistent SQLite evidence.

Scan a prompt

Ollama backend

Install Ollama, pull a model of your choice, and set PG_OLLAMA_MODEL before starting IntentShield. PG_OLLAMA_URL defaults to http://127.0.0.1:11434. The browser cannot supply a backend URL.

Open gateway

Application API

Use a signed-in session with a CSRF token, or set PG_API_TOKEN and send an Authorization: Bearer header. The service token grants scan, batch, document and gateway access only. Server-side secrets are never sent to the browser.

POST /api/scan
{"prompt":"Summarize my notes."}

POST /api/gateway
{"prompt":"Explain unit testing.","backend":"demo"}

POST /api/documents/scan
{"content":"Retrieved document text","source":"retrieval","name":"notes.md"}

Integration reference: Ollama API documentation. Reports and configuration details are in docs/API.md and docs/SECURITY.md.
