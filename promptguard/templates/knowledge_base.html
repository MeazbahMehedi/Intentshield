What is prompt injection?

Prompt injection is an attempt to make an AI system treat untrusted text as instructions, override its intended task, disclose hidden context, or perform an unauthorized action.

  • Direct overrides and jailbreak wording
  • Hidden instructions in documents or retrieved content
  • Attempts to reveal prompts, secrets, or private context
!

Harmful-content warnings

A separate pattern detector checks for requests that appear to seek help with violence, dangerous devices, poisoning, illegal activity, or self-harm.

This warning does not change the injection score. Pattern matching can miss context and is not a determination of a person's intent.

◉

How the score works

Matched findings contribute configured weights. The total is capped at 100 and mapped to a low, medium, or high band.

Low0–24
Medium25–59
High60–100
✓

Safe evaluation practice

Use synthetic prompts, keep secrets out of test data, and review false positives as well as missed attacks.

  • Tune rules on development examples
  • Keep holdout examples separate
  • Report precision, recall, and F1—not accuracy alone
WORKFLOW

Recommended review process

01Scan

Submit a test prompt through the local scanner.

02Inspect

Read matched rules and any separate harmful-content warning.

03Evaluate

Compare predicted labels with known labels across multiple datasets.

04Improve

Add regression tests and measure changes on held-out examples.
